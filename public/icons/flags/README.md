PNG flag assets downloaded from FlagCDN, https://flagcdn.com/w160/{country}.png.
Countries: jp, kr, it, es, fr, de, cn, th, ph, gb. Images are stored locally;
the application makes no runtime requests to that service.

Language codes are mapped separately in lib/curriculum/course-creator.ts.
These flags are visual language-selection cues, not language locale identifiers.
LanguageFlagCard preserves each image's aspect ratio and uses a globe icon if
an image cannot load; accessible language names remain available.
